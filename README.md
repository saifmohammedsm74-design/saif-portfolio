# Saif's Portfolio

A one-page personal portfolio built with plain HTML and CSS. No framework, no build step.

**Live site:** https://saifmohammedsm74-design.github.io/saif-portfolio/

## What's on the page

- About me and what I'm learning
- Skills (Python, Playwright, HTML/CSS, Git)
- Projects, with status for each one
- Languages: Arabic, English, German (working toward B1)
- Contact details

## Run it locally

Open `index.html` in any browser. That's all.

## Deploy

The site is hosted with GitHub Pages from the `main` branch, root folder.

## Updating

Add a new project by copying one `<article class="project">` block in `index.html` and changing the title, text and chips.
